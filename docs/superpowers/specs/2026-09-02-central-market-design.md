# CentralEconomy 中央商品市场设计

## 目标

在 CentralEconomy 内提供不依赖第三方商店插件的玩家对玩家商品市场。市场使用同一 SQLite 账本和同一货币，交易手续费进入国库，形成可审计的货币回笼。

## 首版范围

- `/market` 打开原版 54 格 GUI：浏览有效卖单、按物品筛选、购买和查看自己的卖单。
- 玩家从背包寄存无自定义数据的原版 Material，创建固定单价、固定总量的限价卖单。
- 买家按 1 至剩余数量购买；支付总价，卖家取得扣手续费后的净额，手续费进入 `TREASURY`。
- 撤单将尚未成交物资返还给卖家。
- 每笔创建、成交和撤单写不可变市场审计记录；余额变动全部经过 `LedgerRepository.transferBatch`。

首版不支持自定义名称、附魔、容器内容或其他 NBT/Data Component 物品，不支持买单、竞价、离线投递、跨服和自动价格调节。

## 数据与原子性

SQLite 新增 `market_listings`（卖家 UUID、Material、原始数量、剩余数量、单位价格分、状态、创建时间）和 `market_trades`（卖单 ID、买卖双方、数量、总价、手续费、时间）。

创建卖单：先从在线卖家背包移除纯 Material，再在 SQLite 事务中插入卖单；插入失败立即恢复物品。成交：先校验买家背包可容纳物资，再在一个 SQL 事务中锁定卖单、扣减剩余量、写成交记录，并提交买家到卖家净额和买家到国库手续费的账本批量分录；提交后向买家背包交付物资。若交付失败，写反向资金分录并恢复卖单数量，再记录严重错误。

所有数量、价格与乘法使用边界校验；禁止卖家购买自己的卖单。单价和手续费均以整数分结算。默认手续费 2%，范围为 0–20%，并写入 `market.yml`。

## GUI 与命令

`/market` 打开市场；`/market sell <单价>` 以手持纯物品创建卖单；`/market mine` 显示自己的卖单并允许撤单。GUI 点击卖单后进入数量确认页，防止误购。所有库存事件由自定义 Holder 识别并取消非法拖拽。

## 验收

1. 创建、部分成交、全额成交和撤单不复制或丢失物品。
2. 一笔成交中买家支出 = 卖家净收 + 国库手续费。
3. 余额不足、库存不足、卖单已售罄和自购均不改变状态。
4. 所有市场交易均可按卖单和玩家查询审计。
