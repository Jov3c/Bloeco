# Bloeco 经济内核收缩设计

## 目标

将 Bloeco 固化为 Paper 1.21.11 的反通胀经济基础设施。它只负责货币供给、余额、转账、税收、国库和审计；商店、收购、任务奖励、证券业务等均由独立插件实现。

## 范围

### 保留

- SQLite 双重记账账本，所有金额使用整数分。
- Vault `Economy` 提供者，作为其他插件唯一的玩家余额接入面。
- 玩家 GUI 转账：付款方手续费、收款方个人所得税、原子结算与双方回执。
- 玩家余额查询 GUI。
- 税务管理员 GUI：四种税/费率的调整与持久化。
- 国库 GUI：受确认保护的货币发行、货币回收和 Bloeco-Stock 受限准备金划拨。
- 旧 `CentralEconomy` 数据目录迁移至 `Bloeco`。

### 移除

- 国库物资收购、`procurement.yml`、收购所得税和对应 GUI/服务/测试。
- 玩家商品市场、`market.yml`、物品托管、上架/购买/撤销、市场手续费、消费税和对应 GUI/服务/测试。
- `/market` 命令和商店功能说明。

### 不新增

- Bloeco 不实现商品、物品、价格、库存、任务奖励或证券业务规则。
- Bloeco 不提供绕过 Vault 的第三方余额写入接口。

## 模块边界

| 模块 | 职责 | 禁止事项 |
| --- | --- | --- |
| Bloeco | 货币发行/回收、税收、账本、余额、Vault | 不处理商品与商店库存 |
| 商店插件 | 商品目录、库存、订单、物品交付 | 不得读写 Bloeco SQLite 或自行增发 |
| 任务/奖励插件 | 业务资格与奖励触发 | 必须通过受控 Vault 入账流程，不得伪造账本 |
| Bloeco-Stock | 证券内部账本和交易 | 仅通过 Vault 操作玩家外部钱包 |

## 货币与反通胀规则

1. 玩家之间的转账不创造货币；手续费和个人所得税进入国库。
2. 货币只能由税务管理员在国库 GUI 中发行，并写入 `ISSUE` 账本记录；回收必须写入 `BURN`。
3. 税率按整百分比配置，范围 `0–100`，修改后立即作用于新的结算并写回配置文件。
4. 任何第三方插件的账户变动必须经过 Vault；Bloeco 将其记录为外部贷记或借记，绝不允许第三方直接修改 SQLite。
5. 蓝筹准备金只能从已发行的国库余额划拨，不能替代发行流程。
6. 所有余额变动必须是原子账本操作；余额不足、金额非法或外部结果不确定时失败关闭。

## 对第三方插件的技术规范

### 依赖与服务发现

- 目标平台：Paper `1.21.11`、Java `21`。
- 依赖 Vault API，不依赖 Bloeco 的内部 Java 包或数据库结构。
- 在启用时经 Bukkit `ServicesManager` 解析 `net.milkbowl.vault.economy.Economy`，每次关键结算前重新验证 provider 可用。
- 若 Vault 或 Bloeco provider 不可用，插件必须禁用涉及资金的功能或拒绝本次操作；不得使用本地替代余额。

### 金额与结算

- 只传递有限、非负且最多两位小数的金额；推荐以 `BigDecimal` 或整数分处理。
- 先完成物品/订单等自身的可回滚校验，再调用 Vault 扣款；只有 Vault 成功后才持久化不可逆的业务贷记或交付。
- 若 Vault 调用结果不确定，不自动重试可能已经执行的扣款/入账；进入人工恢复流程。
- 商店插件只能通过 `withdrawPlayer`、`depositPlayer`、`has`、`getBalance` 等 Vault 标准接口结算，不得访问 `plugins/Bloeco/economy.db`。

### 税收责任

- Bloeco 目前自动结算玩家转账手续费和个人所得税。
- 商店插件若需要消费税、交易税或平台手续费，必须在自身订单总价中明确计算，再通过 Vault 原子化的可审计结算流程缴入指定国库路径；不得修改 Bloeco 税率或伪造 Bloeco 账本行。
- 新税种要由 Bloeco 单独扩展并审计后才成为全服统一税制，商店插件不得私自宣称为“中央税”。

## 运维与迁移

- 公共插件名称：`Bloeco`；数据目录：`plugins/Bloeco`；成品名：`Bloeco-<version>.jar`。
- 从 `CentralEconomy` 升级时，仅当目标目录不存在才自动迁移；存在目标目录时拒绝覆盖。
- 必须仅启用一个 Vault Economy provider。部署 Bloeco 前移除或禁用 EssentialsX Economy 等竞争提供者。

## 验收

- 插件不再注册 `/market`，Jar 不再包含市场或收购资源。
- `/bloeco` GUI 只显示余额、转账和授权后的税务/国库入口。
- 既有转账税、国库发行/回收/准备金和 Vault 行为回归通过。
- README 以反通胀经济内核及第三方技术规范为中心。
- GitHub 仓库为公开仓库，未创建 GitHub Release 或标签。
